# Assets

Shared icons, logos and visual assets for my applications and projects.

## Collections

- [Server branding](branding/server/README.md): a shared icon for self-hosted applications.

## Using an asset

GitHub Pages serves files at `https://iyioon.github.io/assets/`.

Use a file's direct URL in an application's icon or logo settings. Prefer SVG when supported; use PNG otherwise. Applications decide where custom artwork appears.

Keep published paths stable. Replacing a file updates applications using its URL, although caches may delay the change. Use a new filename when an immediate refresh is needed.

## Adding assets

Upload files through GitHub's **Add file → Upload files** interface inside the appropriate collection. Use lowercase filenames without spaces and update that collection's README with the file's purpose and URL.

[Server branding](branding/server/README.md) lists the three planned initial files. Their URLs become available after the artwork is uploaded and Pages publishes it.

## Publishing

GitHub Pages publishes from the root of `main`. The empty `.nojekyll` file allows files to be served without Jekyll processing. No build tools or dependencies are required.

## Privacy and reuse

This repository and its published files are public. Upload only artwork intended for public use; do not include credentials, private documents or personal screenshots.

No reuse license is granted by this repository. Confirm ownership and permission before uploading third-party artwork.
