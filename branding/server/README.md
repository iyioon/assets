# Server branding

A shared icon for my self-hosted applications.

## Initial artwork

The following files are planned but have not been uploaded yet. Upload the original artwork into this folder using these filenames. The PNG files must be actual PNG images at the indicated dimensions.

| File | Intended use | Direct URL after upload |
| --- | --- | --- |
| `icon.svg` | Scalable icon where SVG is supported | https://iyioon.github.io/assets/branding/server/icon.svg |
| `web-app-manifest-192x192.png` | Small app icon and PNG fallback | https://iyioon.github.io/assets/branding/server/web-app-manifest-192x192.png |
| `web-app-manifest-512x512.png` | Large app icon and installation artwork | https://iyioon.github.io/assets/branding/server/web-app-manifest-512x512.png |

Prefer SVG where supported. Otherwise use the 512×512 PNG unless an application requests a specific size.

These files provide artwork only. Each application controls whether its custom icon appears in its interface, browser tab or installed web app. Hosting the images does not change an application's web manifest.

After uploading, confirm each URL opens the expected image and update this README to remove the pending-upload notice.
